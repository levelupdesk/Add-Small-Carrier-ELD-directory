# Small-Carrier ELD Directory

A starting point for U.S. owner-operators and small motor carriers comparing electronic logging device (ELD) providers. This directory is an independent research aid, not an endorsement or a determination that a product meets federal requirements.

## Important: verify the exact device

The entries below are **provider leads, not verified ELD devices**. A brand or product page alone does not establish that a particular device is currently registered. Before buying or using an ELD, search the [FMCSA registered ELD list](https://eld.fmcsa.dot.gov/List) for the exact device/model and provider name, and check for revocations or other FMCSA notices. FMCSA explains the ELD requirements on its [ELD information page](https://www.fmcsa.dot.gov/hours-service/elds).

FMCSA's list is the source of record; it is not an endorsement. If an exact model cannot be matched to a current registry entry, treat its status as unconfirmed and contact the provider and FMCSA before relying on it.

## Directory scope and fields

This directory is intended to help small U.S. fleets compare ELD offerings. It includes vendor leads to investigate, but should only describe a specific device as verified after its exact provider and model have been matched against the current FMCSA list. For each verified listing, record:

- Provider and exact product/device model as shown in the FMCSA registry.
- U.S. availability and any relevant service-area limits.
- Hardware, vehicle-connection, installation, and mobile-device requirements.
- Current pricing and billing terms, with a source; use “contact provider” when no price is confirmed.
- Product/source URLs, registry result, and the date each item was checked.

Do not infer device registration, pricing, or compatibility from a provider name or another provider's listing. This repository does not reproduce FMCSA or vendor content; it links to their sources and summarizes only information that has been checked.

## Updating the directory

When adding or refreshing an entry:

1. Open the official FMCSA list and search the exact device/model and provider. Check the current status and relevant notices; do not rely on a brand-level match.
2. Review the provider's own product/support pages for current U.S. availability, hardware and vehicle requirements, and pricing. Link the source for each published fact; mark unavailable or unverified details plainly.
3. Update the review date. Remove or mark a device unconfirmed if it is absent from the current list or appears in a revocation/notice; link to the applicable FMCSA notice.
4. Keep wording factual and neutral. Do not copy vendor marketing text, imply FMCSA endorsement, or present this directory as legal/compliance advice.
